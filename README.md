# Dashboard de Vendas | Power BI

Este foi meu primeiro dashboard desenvolvido em Power BI, durante o curso de Power BI da Data Science Academy.

Para esse projeto, foi utilizado um dataset de uma empresa fictícia que realiza vendas de produtos em diferentes países. A proposta foi analisar os dados de vendas e criar um dashboard capaz de responder algumas perguntas, como o valor total vendido, quantidade de vendas por categoria e país, média de desconto por subcategoria e países com maior média de valor de venda.

O dashboard também possui filtros por ano, segmento e país, permitindo uma análise mais específica dos dados.

Neste projeto, tive meu primeiro contato mais prático com a construção de dashboards no Power BI, trabalhando com visualizações, filtros, medidas e DAX.
